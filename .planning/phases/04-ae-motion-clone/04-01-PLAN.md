<objective>
Develop, deploy, and verify the `ae-motion-clone` skill. This skill ingests any reference animation video or web URL (e.g. Behance, YouTube, Loom, MP4/GIF), decomposes the motion choreography into physical parameters (gravity drop, air wobble, impact overshoot bounce, and stagger offsets), and programmatically maps and injects that motion onto layers of any target composition in Adobe After Effects. It supports selective element filtering (e.g. `--elements-only` to preserve static text) and integrates with `ae-comp-to-gif` for instant 50 FPS smooth GIF previews.
</objective>

<threat_model>
- Risk: Web reference URLs (e.g. Behance modules) blocked by anti-bot checks or complex client-side rendering.
  - Mitigation: Implement dual-mode ingestion: direct CDN extraction via Chrome AppleScript / curl, falling back to local cached media if offline.
- Risk: Applying transforms to layers with pre-existing track mattes causes visual clipping or separation.
  - Mitigation: Detect track matte pairs (`*_mask`, `clippath`) in ExtendScript and automatically link them to parent elements so mattes move in exact synchronization.
- Risk: Hardcoded layer names failing on different compositions.
  - Mitigation: Use semantic categorization heuristics (layer size, aspect ratio, type, naming patterns like `Group`, `polaroid`, `Image`, `Vector`, `Text`) to assign physics behaviors intelligently.
</threat_model>

<tasks>

### Task 1: Skill Specification & Registration (`SKILL.md`)
Create `/Users/admin/.gemini/config/skills/ae-motion-clone/SKILL.md` documenting:
- YAML frontmatter.
- Reference ingestion syntax (local file or URL).
- Built-in physics archetypes: `cascade_drop` (Arôme style), `carousel_scroll`, `elastic_pop`, and `editorial_drift`.
- CLI syntax, options (`--elements-only`, `--comp`, `--duration`, `--stagger`), and ExtendScript integration.

### Task 2: Reference Ingestion & Media Extractor (`fetch_reference.py`)
Develop Python tool to:
- Accept local path or web URL.
- Extract high-quality MP4/GIF from Behance gallery modules, direct CDN links, YouTube, or Loom.
- Cache to `~/.gemini/config/skills/ae-motion-clone/cache/` and emit probe metadata (duration, resolution, framerate).

### Task 3: Motion Profile & Recipe Generator (`motion_analyzer.py`)
Develop Python motion analysis engine:
- Compute frame-by-frame velocity profiles and key event timestamps.
- Match observed motion to physics archetypes (e.g. Arôme sticker cascade drop with rotational tilt and bounce).
- Generate a standardized `motion_recipe.json` containing:
  - Sequence order and stagger timing.
  - Initial offscreen offsets and rotational tilts.
  - Impact bounce curves and overshoot amplitudes.
  - Settle timestamps and temporal ease values.

### Task 4: ExtendScript Motion Injector Core (`apply_motion.jsx`)
Develop ExtendScript automation script for Adobe After Effects:
- Inspect active project and target composition.
- Classify layers into semantic buckets: background, hero elements, stickers/badges, polaroids, and text.
- Apply user filtering (e.g. skip text if `--elements-only` is active).
- Synchronize track matte layers (`_mask`) to root layers.
- Apply cubic bezier easing (`KeyframeEase(speed, influence)`) to position, rotation, and scale keyframes based on `motion_recipe.json`.
- Retime to match target composition duration.
- Save project.

### Task 5: Master CLI Runner (`clone_motion.sh`)
Create unified bash CLI wrapper:
- Usage: `clone_motion.sh --ref <url_or_file> --comp <name> [--elements-only] [--duration <sec>] [--preview-gif]`
- Chaining: Ingests reference $\to$ generates recipe $\to$ injects into AE $\to$ optionally triggers `ae-comp-to-gif` to export a smooth GIF preview.

### Task 6: End-to-End Live Verification

- Verify elements-only motion cascade, natural overshoot bounce, and absence of track-matte clipping.
- Verify smooth GIF preview generation.
