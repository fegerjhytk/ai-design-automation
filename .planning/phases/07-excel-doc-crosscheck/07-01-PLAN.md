<threat_model>
- Risk: Missing third-party libraries (e.g. `openpyxl`, `pandas`) causing failure on minimal environments.
  - Mitigation: Build all parser scripts exclusively on Python 3 standard library modules (`zipfile`, `xml.etree.ElementTree`, `csv`, `json`, `argparse`).
- Risk: Accidental modification of working or open target documents during automated cross-checking.
  - Mitigation: Hardcode an immutable `--dry-run` inspection default and enforce a multi-step approval gate protocol in `SKILL.md` and CLI tools.
- Risk: Threaded comments missing or formatted in legacy XML (`comments*.xml` vs `threadedComment*.xml`).
  - Mitigation: Implement dual-layer fallback to read both modern threaded comments and legacy XML comments seamlessly.
</threat_model>
