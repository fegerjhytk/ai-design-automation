<threat_model>
- Risk: InDesign `do script` AppleScript path errors when passing POSIX paths.
  - Mitigation: Hardcode `(POSIX file "/absolute/path.jsx") language javascript` in all AppleScript runners.
- Risk: InDesign background tasks truncating exported PDFs when documents are closed prematurely.
  - Mitigation: Enforce `while (app.backgroundTasks.length > 0) { $.sleep(250); }` before `doc.close(SaveOptions.NO)`.
- Risk: Unauthorized document mutation or accidental overwrite without user approval.
  - Mitigation: Mandate the Human-in-the-Loop Protocol in `SKILL.md`: agents must present a pre-flight overview and receive explicit approval before executing batch operations.
- Risk: Memory leaks or InDesign hangs when processing dozens of multi-page documents.
  - Mitigation: Implement chunked batching (10–12 documents per execution slice) with atomic document save and close.
</threat_model>
