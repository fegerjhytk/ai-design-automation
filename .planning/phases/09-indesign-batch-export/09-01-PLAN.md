# Phase 09 Plan: InDesign Automated Batch Export & Preflight Engine (`indesign-batch-export`)

## Execution Overview
- **Goal:** Transform the raw batch export script into a standardized, high-performance, autonomous Antigravity skill capable of headless batch conversion, automated preflight error auditing, persistent preferences retention, and single-page PDF splitting.
- **Skill Path:** `~/.gemini/config/skills/indesign-batch-export/`
- **Primary Files:**
  - `SKILL.md` (Skill Specification & Invocation Guidelines)
  - `scripts/batch_export.jsx` (Headless & Interactive ExtendScript Core)
  - `scripts/indesign_batch_export.js` (Autonomous Node.js CLI Runner)

---

## Tasks Breakdown

### Task 1: ExtendScript Core Refactoring & Headless Acceleration
- **Action:** Refactor `Batch Export.jsx` to support headless opening:
  - Replace `app.open(file)` with `app.open(file, false)` to bypass document window construction and accelerate throughput by 3x–5x.
  - Implement automated preflight auditing:
    - Missing external links: `lk.status === LinkStatus.LINK_MISSING`
    - Uninstalled/substituted fonts: `fnt.status !== FontStatus.INSTALLED`
    - Overset text stories: `doc.stories[i].overflows === true`
  - Implement lock-file filtering (`~*.idlk` and temp files).
  - Implement memory safety: call `$.gc()` every 5 documents to prevent ECMAScript 3 heap overflow.
  - Implement `app.insertLabel` and `app.extractLabel` for persistent user preferences.

### Task 2: Deliverable Format Extensions & Single-Page PDF Imposition
- **Action:** Add support for companion IDML generation and zero-padded single-page PDF splitting:
  - Companion IDML checkbox/flag: exports an `.idml` archive alongside Print PDF without re-opening the document.
  - Single-page PDF splitting: iterates `doc.pages`, sets `app.pdfExportPreferences.pageRange = pName`, and formats output filename with zero-padded suffix (`_p001.pdf`).
  - Preflight summary report generation: writes `Batch_Export_Report.txt` to output directory with timestamp, file list, warnings, errors, and elapsed time.

### Task 3: Autonomous Node.js CLI Runner Development
- **Action:** Develop `indesign_batch_export.js` to enable zero-click execution from terminal or Antigravity chat agents:
  - Support command-line arguments: `--input`, `--output`, `--format`, `--preset`, `--suffix`, `--single-pages`, `--also-idml`, `--no-subfolders`.
  - Pass parameters to InDesign via AppleScript `tell script args set value name ...`.
  - Execute headless ExtendScript via `do script POSIX file ... language javascript`.
  - Parse and print preflight summary report directly to stdout.

### Task 4: Antigravity Skill Specification & Registration
- **Action:** Author `SKILL.md` in `~/.gemini/config/skills/indesign-batch-export/SKILL.md`:
  - Enforce proper YAML frontmatter with `name` and descriptive `description`.
  - Document key capabilities, CLI options, interactive InDesign installation steps, and example prompts.

### Task 5: Verification & End-to-End Validation
- **Action:**
  - Verify syntax of `indesign_batch_export.js` with `node -c`.
  - Test CLI argument parser and `--help` output.
  - Document verification results in `09-VERIFICATION.md`.
  - Synchronize roadmap, requirements, and project state.
