<objective>
Build, scaffold, and register the `brand-engine-mcp` plugin in `~/.gemini/config/plugins/brand-engine-mcp/`. This converts the user's manual design and animation workflows into a deterministic, zero-hallucination Model Context Protocol (MCP) server that interfaces with Adobe Illustrator CC, Google Flow, Whisper, GSAP, and OpenAI Codex.
</objective>

<threat_model>
- Risk: Missing `@modelcontextprotocol/sdk` dependency causing server crash on load.
  - Mitigation: Build with a lightweight, standalone zero-dependency JSON-RPC stdio protocol handler (or bundle SDK) so the MCP server runs on native Node.js immediately without requiring complex npm install steps.
- Risk: Illustrator modal prompts blocking automated ExtendScript execution.
  - Mitigation: Wrap all ExtendScript execution in `app.userInteractionLevel = UserInteractionLevel.DONTDISPLAYALERTS` and execute via macOS `osascript`.
- Risk: Audio file path missing or unreadable in `motion_sync_timeline`.
  - Mitigation: Validate file presence using `fs.existsSync` and provide fallback mock timelines for rapid prototyping.
</threat_model>

<tasks>

### Task 1: Plugin Manifests & Metadata
Scaffold `/Users/admin/.gemini/config/plugins/brand-engine-mcp/`:
- `plugin.json`: Metadata, display name ("Brand & Motion Engine MCP"), version 1.0.0, description, and suggested prompts.
- `mcp_config.json`: Server command (`node`), args (`server.js`), and default environment variables.
- `package.json`: Project manifest.

### Task 2: Core Stdio MCP Server (`server.js`)
Develop a clean, resilient JSON-RPC 2.0 stdio server supporting:
- `tools/list`: Declaring schemas for the 6 core tools.
- `tools/call`: Routing arguments to specialized handler modules in `lib/`.
- Error handling and structured JSON responses conforming to MCP specification.

### Task 3: Anti-Sameness & Kerning Engines (`lib/anti_sameness.js`, `lib/kerning.js`)
- `lib/anti_sameness.js`: Implements category deconstruction logic, trope detection (colors, fonts, icons, buzzwords), counter-anchor generation, and negative prompt formatting.
- `lib/kerning.js`: Scans letter pairs (`R-A`, `T-o`, `A-V`, `P-e`) and returns optical tracking calibrations.

### Task 4: Illustrator Automation Core (`lib/illustrator.js`)
- Executes ExtendScript via `osascript` to build master `.ai` documents on Desktop.
- Sets up unflattened layer hierarchy (`Wordmark (Hero)`, `Secondary Seals`, `Atmospheric Gradients`, `Dielines`).
- Respects `autonomous-designer-core.md` (keeps Illustrator live, creates native graphic styles).

### Task 5: Motion Sync & Environmental Staging (`lib/motion.js`, `lib/stage.js`)
- `lib/motion.js`: Converts audio timing markers into GSAP easing timelines (`linear`, `power2.out`, `elastic.out`).
- `lib/stage.js`: Assembles Google Flow directorial prompts with Nano Banana 2.1 settings and aspect ratio enforcement.

### Task 6: Plugin Rules & Verification (`rules/AGENTS.md`)
- Author `rules/AGENTS.md` guiding agents on tool usage.
- Run node syntax check on `server.js` and verify standard JSON-RPC handshake.
</tasks>
