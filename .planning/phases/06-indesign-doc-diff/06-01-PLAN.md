<objective>
Develop, package, and deploy the `indesign-doc-diff` skill in `~/.gemini/config/skills/indesign-doc-diff/`. The skill must provide full-spectrum deep comparison of Adobe InDesign (.indd) documents, extract precise typography & spacing hierarchies, audit table structures and cell insets, preflight broken links and missing fonts, and deliver clean reports in terminal markdown or JSON format.
</objective>

<threat_model>
- Risk: InDesign dialog alerts (e.g. missing fonts, missing links, modified links) blocking script execution.
  - Mitigation: Set `app.scriptPreferences.userInteractionLevel = UserInteractionLevels.NEVER_INTERACT` in ExtendScript before opening documents.
- Risk: Documents open in read-only or lock files (`.idlk`) interfering with inspection.
  - Mitigation: Open documents with `open(File(path), false)` (without window display if possible, or gracefully query existing open documents).
- Risk: Multi-line story text causing JSON formatting breaks or memory bloat.
  - Mitigation: Sanitize all string snippets, escape quotes, and clamp text snippets to 100 characters when `--exclude-content` is enabled.
</threat_model>

<tasks>

### Task 1: Skill Specification & Registration
Create `/Users/admin/.gemini/config/skills/indesign-doc-diff/SKILL.md` with progressive disclosure documentation, triggers, CLI flag reference, and usage examples for both single-file typography audits and two-file diff comparisons.

### Task 2: ExtendScript InDesign Deep Inspector Engine (`indesign_inspector.jsx`)
Develop the headless InDesign inspection script:
- Safely targets an open or closed `.indd` document.
- Suppresses all modal alerts (`NEVER_INTERACT`).
- Gathers document dimensions, bleeds, page-by-page parent/master spreads, margins, and column gutters.
- Inspects all page items: geometry bounds, constructor types, grouping hierarchy, and overset text flags (`overflows`).
- Deep-inspects all `Table` objects across stories: rows, columns, header rows, row heights, column widths, and cell insets (top, bottom, left, right).
- Extracts typography: font family, style/weight, point size, leading (auto % vs fixed pt), tracking, kerning, paragraph alignment, and space before/after.
- Gathers link preflight: link name, path, status (`NORMAL`, `LINK_MISSING`, `LINK_OUT_OF_DATE`).
- Gathers font preflight: font name, postscript name, status (`INSTALLED`, `NOT_AVAILABLE`).
- Gathers swatch palette: swatch names, color values, color spaces (RGB, CMYK, Spot/Pantone).
- Serializes and writes complete document profile to JSON.

### Task 3: CLI Runner & Diff Engine (`indesign-doc-diff.js` & `run_diff.sh`)
Develop the Node.js CLI orchestrator:
- Implements CLI commands:
  - `--compare <docA.indd> <docB.indd>`: Compares two InDesign files.
  - `--inspect-typo <doc.indd>`: Generates a typography hierarchy and design token map for a single document.
  - `--exclude-content`: Excludes text copy differences to focus solely on layout, typography, tables, and structure.
  - `--json`: Outputs raw JSON delta for programmatic downstream pipelines.
  - `--markdown`: Outputs GitHub-flavored markdown report.
- Features clean, formatted terminal tables and markdown cards highlighting layout shifts, table changes, broken links, missing fonts, and palette deltas.
