<objective>
Develop, deploy, and verify the `ae-comp-to-gif` skill in `~/.gemini/config/skills/ae-comp-to-gif/`. The skill programmatically controls Adobe After Effects 2026 to export any composition into butter-smooth, non-lagging GIFs. It automatically selects the optimal GIF-compliant framerate (50/25/20 FPS), synchronizes nested sub-comp durations, protects seamless loops from seam pausing, encodes two-pass differential color palettes, and provides both master and lightweight web-ready deliverables with verified constant frame timing.
</objective>

<threat_model>
- Risk: After Effects hangs or prompts a modal dialog during automated render.
  - Mitigation: Execute via AppleScript with timeout wrapping, set `app.userInteractionLevel = UserInteractionLevel.DONTDISPLAYALERTS`, and clear old render queue items before adding new items.
- Risk: GIF file size balloons (>100MB) for long compositions.
  - Mitigation: Automatically recommend 25 FPS for comps > 8s, and always generate a companion 1024px Web-Optimized GIF (128 colors, Lanczos downscale) to prevent browser/RAM lag.
- Risk: User requests 60 FPS or 24 FPS without realizing the GIF clock causes stutter.
  - Mitigation: Automatically explain the 10ms clock quantization rule and offer the 50 FPS harmonic as the jitter-free equivalent, while honoring an explicit override if forced.
</threat_model>

### Task 2: ExtendScript AE Automation Core (`ae_export.jsx`)
Develop `/Users/admin/.gemini/config/skills/ae-comp-to-gif/scripts/ae_export.jsx`:
- Find target composition by name or target active composition.
- Adjust composition frame rate to requested or calculated harmonic (default 50 FPS).
- If duration is modified, recursively update all nested `CompItem` layers and sub-comps, extending `inPoint = 0` and `outPoint = newDuration`.
- Identify looping parent nulls / position keyframes; align keyframes to $t=0$ and $t=\text{duration}$ with linear interpolation to maintain constant velocity and seamless looping.
- Configure Render Queue (`H.264 - Match Render Settings - 15 Mbps`) to output intermediate MP4.
- Trigger render synchronously and report status JSON to disk.

### Task 3: Python Two-Pass Smooth GIF Converter (`convert_to_smooth_gif.py`)
Develop `/Users/admin/.gemini/config/skills/ae-comp-to-gif/scripts/convert_to_smooth_gif.py`:
- Parse video stream metadata via `ffprobe` (dimensions, fps, duration).
- Select harmonic FPS if not locked (e.g. 50 FPS for high-motion, 25 FPS for >8s).
- Run Pass 1: FFmpeg palette generator with `stats_mode=diff` to prioritize moving pixels.
- Run Pass 2: Palette use with `dither=bayer:bayer_scale=3` to generate Master GIF.
- Generate Web-Optimized GIF (scaled to 1024px with `max_colors=128`).
- Verify packet duration using `ffprobe pkt_duration_time`: verify 100% of packets match the constant delay.
- Print structured markdown summary with file links, sizes, and verification stats.

### Task 4: Unified Shell Runner (`ae_to_gif.sh`)
Develop `/Users/admin/.gemini/config/skills/ae-comp-to-gif/scripts/ae_to_gif.sh`:
- Provide clean CLI options: `--comp "<name>"`, `--duration <sec>`, `--fps <50|25|20|auto>`, `--out <dir>`.
- Orchesrate the ExtendScript execution in AE, then pass rendered video to `convert_to_smooth_gif.py`.
- Handle permission checks and make script executable (`chmod +x`).
