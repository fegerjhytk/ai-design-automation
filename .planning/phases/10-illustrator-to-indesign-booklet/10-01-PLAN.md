## Tasks Breakdown

### Task 1: Deep Asset Harvesting & Vector Asset Extraction from Illustrator
- **Action:**
  - Develop and execute `harvest_booklet_assets.jsx` in Adobe Illustrator CC.
  - Extract structured JSON manifest of all 4 artboards:
    - Text frame bounds, baseline coordinates, font families, weights, point sizes, leading, tracking, text alignments, and raw story strings.
    - Path geometries: divider lines, stroke weights, corner accents, and background fills.
    - Exact color definitions: CMYK swatches (`Cobalt Accent: CMYK 86,74,0,0`, `Primary Charcoal: CMYK 75,68,67,90`, `Quote Dark: CMYK 95,86,48,62`, `Quote Mid: CMYK 50,31,0,0`, and `Solid Black: Process Black`).
  - Export vector artwork assets for embedded/subset display typography:
    - Export "SET APART" display wordmark from Artboard 3 as a native vector asset (`Links/wordmark_set_apart.pdf` or `.eps`) to ensure 100% vector sharpness and zero missing font dependencies in InDesign.
    - Export quote glyphs and decorative vector shapes for Pages 2 and 4.
  - Export high-resolution 300 PPI reference PNGs of all 4 Illustrator artboards into `QC/ai_renders/` for downstream visual comparison.

### Task 2: Native 4-Page InDesign Document Construction
- **Action:**
  - Author and execute `build_indesign_booklet.jsx` in `Adobe InDesign 2027` via AppleScript / ExtendScript.
  - Set up Document Setup:
    - Pages: 4, Facing Pages: false (or spread-compatible), Page Width: 612 pt, Page Height: 792 pt (US Letter).
    - Margins: Top 64.96 pt, Bottom 67.87 pt, Inside/Left 73.09 pt, Outside/Right 73.09 pt.
  - Create standard Swatches:
    - `Patria_Cobalt` (`CMYK: 86, 74, 0, 0`)
    - `Patria_Charcoal` (`CMYK: 75, 68, 67, 90`)
    - `Patria_Quote_Dark` (`CMYK: 95, 86, 48, 62`)
    - `Patria_Quote_Mid` (`CMYK: 50, 31, 0, 0`)
  - Create standardized Paragraph & Character Styles:
    - `Booklet / Kicker` (`CoFo Sans VF`, Medium, 10.8 pt, all-caps, tracking 100)
    - `Booklet / Hero Title` (`Cormorant Garamond`, Light Italic, 90 pt)
    - `Booklet / Section Title` (`Cormorant Garamond`, Light Italic, 40 pt)
    - `Booklet / Signoff` (`Cormorant Garamond`, Light Italic, 57.5 pt)
    - `Booklet / Scripture Callout` (`Cormorant Garamond`, Light Italic, 25 pt, leading 32 pt)
    - `Booklet / Body Text` (`CoFo Sans VF`, Regular, 12 pt, leading 16.5 pt)
    - `Booklet / Week Heading` (`CoFo Sans VF`, Medium, 8.1 pt, all-caps, tracking 80)
    - `Booklet / Week Subtitle` (`Cormorant Garamond`, Light Italic, 25 pt)
    - `Booklet / Week Theme` (`CoFo Sans VF`, Regular, 12 pt)
    - `Booklet / Running Folio` (`CoFo Sans VF`, Regular, 7 pt, letterspaced)
  - Build Page Elements:
    - **Page 1:** Kicker "PATRIA FAMILY FAST", Display Title "Hey Family", body paragraph, decorative rule, Table of Contents block (01 through 05 items), cobalt corner square, and running footer.
    - **Page 2:** Solid black background rectangle, "A BLESSING FOR YOU", Scripture blessing (Numbers 6:24–26) with styled quote marks, signoff "We love you." and "Team Patria", and corrected running footer "02".
    - **Page 3:** Kicker "THIS YEAR’S FAST", placed high-res vector "SET APART" wordmark, Romans 12:2 reference, scripture block with vertical cobalt rule, body intro, horizontal divider rule, and 3-column weekly grid (Weeks 1, 2, 3) with aligned baselines, and running footer "03".
    - **Page 4:** Kicker "Part One", Section Title "The Definition of Fasting", body opening, Matthew 6:16 callout with oversized quote marks, concluding body block, and corrected running footer "04".
  - Save native document to `/Users/admin/Desktop/21_Days_Fast_FastBooklet.indd`.

### Task 3: Production Export & Companion IDML Generation
- **Action:**
  - Use the `indesign-batch-export` pipeline to generate production deliverables:
    - Export Press Quality Print PDF to `/Users/admin/Desktop/21_Days_Fast_FastBooklet.pdf`.
    - Export Companion InDesign Markup Archive to `/Users/admin/Desktop/21_Days_Fast_FastBooklet.idml`.
    - Export individual page review PNGs (Pages 1 to 4 at 300 PPI) into `QC/id_renders/`.

### Task 4: Automated Preflight Audit
- **Action:**
  - Execute programmatic preflight validation in InDesign:
    - **Missing Fonts:** Assert `doc.fonts.everyItem().status` has zero missing/substituted fonts.
    - **Missing Links:** Assert `doc.links.everyItem().status` has zero `LinkStatus.LINK_MISSING`.
    - **Overset Stories:** Inspect all `doc.stories` to assert `overflows === false`.
  - Log audit results to `Preflight_Audit_Report.txt`.

### Task 5: Visual Diff Comparison & Quality Verification
- **Action:**
  - Execute `visual_diff_engine.py` from `~/.gemini/config/skills/design-qc-visual-diff/` comparing:
    - Baseline: `QC/ai_renders/` (Artboards 1–4 from Illustrator)
    - Candidate: `QC/id_renders/` (Pages 1–4 from InDesign)
  - Generate visual diff composite images and audit delta statistics.
  - Document all results in `10-VERIFICATION.md`.
