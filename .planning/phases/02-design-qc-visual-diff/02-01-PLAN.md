<objective>
Develop, deploy, and verify the `design-qc-visual-diff` skill. The skill must provide full-spectrum quality control audits for Adobe Illustrator deliverables and visual comparison rendering in both side-by-side "image mode" and annotated "marked mode" with highlight boxes and numbered pins.
</objective>

<threat_model>
- Risk: Pillow missing in system python.
  - Mitigation: Execute Python image processing through `uv run --with pillow python3`, which is installed and verified.
- Risk: Illustrator modal dialogs or alert interruptions during automated artboard export.
  - Mitigation: Set `app.userInteractionLevel = UserInteractionLevel.DONTDISPLAYALERTS` in all ExtendScript scripts.
- Risk: Non-printing marker layers lingering in final deliverables.
  - Mitigation: Tag marker layer with `printable = false` and provide a clean `remove_markers` action.
</threat_model>

<tasks>

### Task 1: Skill Specification & Registration
Create `/Users/admin/.gemini/config/skills/design-qc-visual-diff/SKILL.md` with progressive disclosure documentation, triggers, command line interfaces, and step-by-step execution guides.

### Task 2: ExtendScript QC Audit Engine (`qc_auditor.jsx`)
Develop the deep document auditor:
- Extract all fills, strokes, and text colors.
- Match text label HEX codes against adjacent swatch fills to detect mismatch bugs.
- Validate font family distribution against brief constraints (e.g., exactly 1 headline family).
- Detect conflicting slide options and copy-paste residual text.
- Export results as clean JSON.

### Task 3: Artboard Exporter (`export_artboards.jsx`)
Develop high-res PNG exporter supporting selective or batch artboard exports at 150/300 ppi without UI dialogs.

### Task 4: Visual Diff & Marked Comparison Engine (`visual_diff_engine.py`)
Develop Python visual diffing engine:
- Side-by-side image mode composite generator.
- Marked diff mode with bounding box clustering, high-visibility red highlight strokes, and numbered badges.
- Self-contained HTML interactive comparison dashboard.

### Task 5: In-Illustrator On-Canvas Marker Tool (`mark_diff_in_illustrator.jsx`)
Develop script to draw the non-printing `[QC_DIFF_MARKERS]` layer with red highlight boxes and callout labels directly on the Illustrator artboard.

### Task 6: CLI Runner & Test Verification
Create `run_qc.sh` and execute end-to-end verification against the live LIP test files (`_v2_backup.ai` vs `_v2.ai`).
</tasks>
