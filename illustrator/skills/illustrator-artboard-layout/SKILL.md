# Illustrator artboard layout

Work in the Illustrator document the user specifies. An open document is the destination when the user asks to work in the open file. Deliver the layout there and export files only when requested.

## Inspect the document

- Identify the active document, target artboards, and reference artboard before writing. Inspect their dimensions, current artwork, text margins, typefaces, and brand colors. Use attached screenshots as visual references. Confirm the actual fonts and objects from the document where available.
- Preserve finished slides, existing artwork outside the requested area, and the user's unsaved work. Use already prepared artboards when appropriate. Create artboards only for missing slides or when the user asks for new ones.
- Respect any explicit start cue for the current assignment. Before that cue, inspect and plan within scope and leave the document untouched.

## Place the content

- If the user supplies a slide breakdown, follow it. When they delegate the split, group related ideas into slide-sized units. Preserve supplied wording, punctuation, numbers, and labels unless editing is requested. Use line breaks, hierarchy, and typography to fit longer copy.
- Reuse editable type styles and the original logo, QR code, and other requested assets from the file. Match reference margins and alignment. Keep the original scale and proportions of brand assets. Avoid stacking a second copy over an existing logo or QR code.
- Choose charts that answer the slide's question. Use a common zero baseline for comparable bar lengths, a ranked bar chart for ordered values, and a proportional stacked bar or ring for shares of a whole. Label using the supplied values and units. If the data is rounded, derive proportions from the underlying counts when available. Preserve the supplied display labels and flag material discrepancies.
- Prefer live text and editable vector shapes. Keep added artwork grouped by slide or in a named layer so it is easy to revise.

## Apply and verify

- Use an available Illustrator document-editing interface. For UI-only access, use the supported computer-use tool. When native Illustrator document scripting is available and appropriate, use it through Illustrator's supported workflow. Scope batch edits to the verified document and explicit artboards. Use temporary files for implementation resources unless the user requests those files.
- Recheck the active document and artboards immediately before a batch edit, especially after a modal or document switch. When duplicating an artboard with artwork, avoid moving it across positions occupied by existing artboards. Illustrator can pick up artwork at an overlapping position on a subsequent move. Verify the copy and its contents before repeating.
- Inspect the full artboard sequence, then zoom in on long labels and chart details. Check slide order, copy and values, logo and QR placement, text fit, and gaps or overlaps. Confirm that finished slides still match their starting state. Verify an in-place save when the task calls for it.
- If a modal blocks the edit, refresh the app state and check whether it is frontmost before retrying. If the app still requires user interaction, name the exact dialog and the smallest action needed. Report which edits are present and whether they were saved if the work remains partial.
