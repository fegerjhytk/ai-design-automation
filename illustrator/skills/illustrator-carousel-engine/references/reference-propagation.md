# Propagate a design reference

Use this workflow when the user names an Illustrator file or artboard as a design reference.

1. **Bind the source and targets.** Record the exact source file or live document, the human-facing artboard number and name, its scripting index, and the target document and artboards. When a user makes a newer explicit artboard choice for the same deliverable, use that source. Carry each unfinished reference job separately when the conversation moves to another carousel.
2. **Capture the reference.** Use the current version, including intended unsaved edits. Record artboard-relative bounds and stacking for the quote, image or mask, attribution, backdrop, texture, and other applicable roles. Record text anchors, style runs, justification, and spacing, plus image opacity and crop behavior. Identify clipped artwork by matching its actual artboard mask; its group bounds can extend far beyond that mask. Inspect nested groups for editable text and placed artwork. Capture a read-only preview when available. A filename, a palette, or a preview alone does not establish which layout properties will transfer.
3. **Apply that structure to one target.** If practical, duplicate the reference artwork into a verified working area and replace content in mapped slots. After moving or duplicating artwork between documents, compare the translated clipping path and text anchors to the intended artboard, and correct any coordinate offset before editing. If duplicating the artwork is impractical, construct the target from recorded source properties and keep existing target objects where appropriate. Preserve each target's copy and image assignment. Scope any replacement to the mapped role. Avoid clearing an entire layer or deleting by artboard overlap alone.
4. **Honor content-first placement when requested.** Set and check the target text with an empty or placeholder image slot before placing or relinking final images. Keep asset preparation separate from placement. Honor format, location, and access restrictions during both stages.
5. **Compare the output with the source.** Inspect a current preview of the first actual target beside the reference before applying the batch. Check alignment, relative position, spacing, style, stacking, and crop by role. A new image or longer quote can need an adjustment. Check that longer lines still sit over a readable part of the background. Adjust phrase breaks or fit within the text region when needed, keeping the reference hierarchy. Disclose meaningful deviations. If the user requested approval for a first slide, wait for it. Otherwise continue after the first slide passes.
6. **Verify the propagation actually ran.** Record whether the change is prepared, applied, verified, and saved. A generated script is only preparation. Verify each output against the intended reference and preserve the source artboard where it is outside the target set. Check for stranded words, touching image boundaries, stray crops, hidden copy, and wrong slide exports. If interrupted, carry forward the actual state before making a completion claim.

Adobe documents duplication of an artboard with its artwork and targeted export through the Artboard tool. [Artboard context menu](https://helpx.adobe.com/illustrator/desktop/create-manage-artboards/organize-manage-artboards/use-artboard-context-menu.html)
