# Run multi-artboard jobs efficiently

Keep the first-slide reference comparison, safeguards for user edits, and final visual checks. Reduce repeated host work between those checkpoints.

- **Read once per stable document state.** In one scoped inspection, collect source role geometry and styles, target artboard identities, relevant links, and required fonts. Reuse that snapshot within the batch. Refresh affected data if the document, reference, assets, or target content changes.
- **Keep lookups local to the work.** Index identified target objects and resolve reusable fonts and swatches once per batch. Use known object references or stable groups to update content. Avoid rescanning every item for each slide or running a separate host command for each property.
- **Use a pilot, then a batch.** Inspect and apply one representative target, compare it with the reference, and then apply the verified mapping to the remaining targets in one bounded host invocation where practical. Keep explicit checkpoints for any outlier, ambiguity, or user edit. Report completed artboards and per-artboard failures.
- **Render the views you will use.** Compare the reference and pilot at a readable size, then export changed artboards together for the final review when available. Use full-size crops for small copy or uncertain fit. Check that each preview corresponds to the intended artboard. Produce full-size delivery exports only for requested outputs. [Adobe Export for Screens](https://helpx.adobe.com/illustrator/desktop/save-and-export/export-files-to-different-formats/export-artboards-and-assets-for-screens.html)
- **Reuse verified assets and defer redundant writes.** Link existing assets when the brief allows and keep their relative paths. In a portable working copy, resolve expected asset paths once, reuse confirmed local links, and relink stale or external paths only to verified authorized files. Prepare shared links before duplicating the group where practical. If a link operation stalls, check for an Illustrator interaction request before attempting a retry. Convert or prepare each distinct local asset only as needed. Save at meaningful checkpoints and verify the final saved file. Adobe notes that linked images can help reduce document size and improve performance. [Adobe Illustrator performance settings](https://helpx.adobe.com/illustrator/desktop/get-started/preferences-and-settings/optimize-illustrator-settings-for-performance.html)
- **Measure before claiming a speedup.** Record elapsed time by stage when speed is being evaluated. Compare equivalent runs on the same fixture, asset set, output sizes, and verification steps. Separate one-time setup and troubleshooting from apply, render, and save. A single live test establishes observed timings rather than a before-and-after improvement.
