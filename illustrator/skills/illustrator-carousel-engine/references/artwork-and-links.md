# Artwork and links

## Source and prepare assets

- Use user-provided files and approved libraries first. Search Pinterest only when requested. Use supported search or browser tools when necessary, within the access actually available. Use references for layout analysis unless the source image is appropriate and authorized for placement.
- For a supplied web page, identify the intended image and the suitable available variant. Check the asset decodes and matches the reference. Preserve transparency, color, and orientation when converting, and keep original sources intact. Respect access restrictions and avoid assuming that a predictable URL supplies a valid or authorized source.
- Check the useful cropped pixel dimensions against the intended export for social media. For print, check effective PPI at placed size against the production spec. Choose an asset that meets the intended output without treating a single pixel threshold as a print or screen guarantee.
- In the standard project layout, store only the actual project assets in `Links/`. Use distinct filenames for different content, reuse verified identical assets where appropriate, and verify the link after placement or after moving a working copy.

## Place, clip, and relink

- Scale a cover photo proportionally to fill the target artboard. Derive the mask from that artboard's actual bounds and keep the focal point in view. Place the clipping path above the contents, the scrim above the image inside the mask, and the editable type above the group. Verify both the group structure and the rendered edges and contrast.
- Relink the intended placed item. Match the document, artboard or parent group, object identity, and expected old link where available. Use Illustrator's supported relink operation and verify the replacement path and resulting crop or position. A shared source can appear multiple times. Replace all instances only when that is the requested scope.
- Check the affected Links panel entries or equivalent document data for missing or modified links. Inspect affected and adjacent artboards for unintended image changes, masks that spill, low contrast, or empty edges. Package linked assets with the Illustrator file when packaging is requested.

Adobe references: [Create clipping masks](https://helpx.adobe.com/illustrator/desktop/manage-objects/edit-objects/create-clipping-masks.html), [Relink or replace linked files](https://helpx.adobe.com/illustrator/desktop/add-and-import-files/manage-linked-and-embedded-files/relink-replace-or-update-linked-files.html), and [Links information](https://helpx.adobe.com/in/illustrator/using/links-info.html).
