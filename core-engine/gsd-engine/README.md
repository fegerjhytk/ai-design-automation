# Get Shit Done (GSD) for Antigravity

A meta-prompting, context engineering, and spec-driven development workflow system installed directly into Antigravity.

## Quick Commands

- `/gsd-help` — Show all available GSD commands and usage guide
- `/gsd-new-project` — Initialize a new spec-driven GSD project (`PROJECT.md`, `REQUIREMENTS.md`, `ROADMAP.md`)
- `/gsd-plan-phase` — Create detailed execution plans (`PLAN.md`) for a roadmap phase
- `/gsd-execute-phase` — Execute phase plans with fresh subagent context and atomic commits
- `/gsd-verify-work` — Validate built features against phase goals

## CLI Installation Reference

- **Global**: `npx get-shit-done-cc@latest --antigravity --global`
- **Local (project-only)**: `npx get-shit-done-cc@latest --antigravity --local`
